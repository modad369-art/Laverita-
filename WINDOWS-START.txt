LAVERITA 홈페이지 확인 방법
============================

1. 이 ZIP 파일을 마우스 오른쪽 버튼으로 누릅니다.
2. "모두 압축 풀기"를 선택합니다.
3. 압축이 풀린 새 폴더를 엽니다.
4. index.html 파일을 더블클릭합니다.

기본 웹 브라우저에서 라베리따 홈페이지가 열립니다.
상단의 메인, 브랜드, 컬렉션, 맞춤 제작 메뉴를 눌러 페이지를 이동할 수 있습니다.

중요:
- index.html만 따로 옮기지 마세요.
- assets 폴더와 다른 HTML 파일도 같은 위치에 있어야 이미지와 디자인이 보입니다.
- 작품 이미지는 assets/css/artwork-data.css 안에 Base64 텍스트로 포함되어 있습니다.
- 별도의 설치나 인터넷 연결은 필요하지 않습니다.
- 이 파일들은 검토용이며 인터넷에 공개 배포되지 않습니다.
